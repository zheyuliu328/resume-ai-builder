# Decadal Plan (Milestone Roadmap)

> This roadmap is ordered by: **Survival → Efficiency → Intelligence → Expansion → Autonomy**.
> 
> **Rule:** We do *not* skip foundations. Each phase assumes the previous phase is stable.

## Phase I — Foundation & Industrialization (V1.x)
### 1) V1.1 — Operation Ironclad (Steel Defense)
- Goal: Data safety, atomic rollback, evidence chain completeness.

### 2) V1.2 — The Logistics Pipeline
- Goal: CI/CD takes over logistics (tag/release/build) with human gates preserved.

### 3) V1.3 — The Cockpit
- Goal: A visual command UI for variants + preview + apply + export intelligence.

## Phase II — Intelligence Awakening (V2.x)
### 4) V2.0 — The Data Refinery
- Goal: Mine patterns across many JDs and resume fragments; gap analytics.
- Note: consider local vector DB *only if* it stays local-first and lightweight.

### 5) V2.1 — Stealth Mode
- Goal: Local LLM backend option (Ollama/etc) to reduce cost + improve privacy.

### 6) V2.2 — The Scout
- Goal: Browser extension for one-click JD capture → target resume pipeline.

## Phase III — Arsenal Expansion (V3.x)
### 7) V3.0 — The Diplomat
- Goal: Cover letter + cold email generation using existing `_meta` evidence.

### 8) V3.1 — The Portfolio Generator
- Goal: Generate a public (optional) portfolio site from resume JSON.

## Phase IV — The Singularity (V4–V5)
### 9) V4.0 — The Mock Interviewer
- Goal: Voice interview training (STT/TTS) tied to target JD + resume.

### 10) V5.0 — The Autonomous Career Agent
- Goal: Auto-apply via RPA with strict human approval gates and audit logs.

## Governance Notes
- VISION.md is the constitution; ADRs are binding history.
- Any new capability must be:
  - local-first by default,
  - controllable (preview→apply),
  - auditable (evidence chain),
  - reversible (rollback).
